 # Preentrega-1-backend3-coderhouse 
 
 ## Mocking API 
 
 ### Descripción 
 API para la adopción de mascotas desarrollada con **Node.js**, **Express** y **MongoDB**. 
 
 ### Instalación 
 1. Clona el repositorio: 
    ```bash 
    git clone <repo_url> 
    cd adoptme-api 
    ``` 
 
 2. Instala las dependencias: 
    ```bash 
    npm install 
    ```
    
 3. Crea un archivo `.env` con la configuración necesaria (por ejemplo, la URL de MongoDB y el puerto): 
    ```env 
    MONGODB_URI=mongodb://localhost:27017/adoptme 
    PORT=3000 
    ``` 
 
 ### Documentación 
 
 La documentación Swagger de la API está disponible en: 
 
 [http://localhost:3000/api-docs](http://localhost:3000/api-docs) 
 
 ### Ejecución de Pruebas 
 
 Para ejecutar la suite de pruebas, usa: 
 
 ```bash 
 npm test 
 ```
